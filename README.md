## 🚀 Cómo subirla a GitHub Pages

1. Abre una terminal en esta carpeta (`MyProfileAsesor`) y ejecuta:
   ```bash
   git init
   git add .
   git commit -m "feat: landing page profesional profesor de programacion"
   git branch -M main
   git remote add origin https://github.com/Joelru/TU-REPOSITORIO.git
   git push -u origin main
   ```
2. En tu repositorio de GitHub ve a **Settings** → **Pages**.
3. En **Build and deployment** → **Branch**, selecciona `main` y carpeta `/ (root)` y haz clic en **Save**.
4. ¡Listo! En 1 minuto tu página estará publicada en `https://joelru.github.io/TU-REPOSITORIO/`.
